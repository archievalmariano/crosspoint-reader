# v1.4.0: the app suite on CrossPoint 2.0

Changes since v1.3.0. This release moves GOTO, ON POINT, DOGEAR and Tools onto CrossPoint 2.0.0. The apps themselves
work as they did in v1.3.0.

## What's new from CrossPoint 2.0

The reader, Settings and Library come from CrossPoint 2.0.0:
- Highlights and clippings in EPUBs.
- Better EPUB formatting, including drop caps, tables and borders.
- More line-spacing choices.
- Settings grouped into sections.
- A refreshed web interface for File Transfer.
- Bluetooth page turners and SD card plugins.

See the [CrossPoint 2.0.0 release notes](https://github.com/crosspoint-reader/crosspoint-reader/releases/tag/2.0.0)
for the full list.

## Before you update

**Noto Serif is now an optional SD card font for the reader.** If you read in Noto Serif, install `NotoSerif` through
Manage Fonts, before or after updating. GOTO and DOGEAR keep their own built-in serif and don't need it.

**Your data carries over.** Your settings, ON POINT collections and main routes, Wi-Fi networks, recent books and
DOGEAR and GOTO copies stay on the card. On first start, CrossPoint 2.0 updates some reader settings to its new
format, including font and line spacing.

**Going back to v1.3.0** can leave the reader on a different font or line spacing, because of that update.

## Not tested on this release

Bluetooth page turners come from CrossPoint 2.0 and weren't tested with the app suite.
