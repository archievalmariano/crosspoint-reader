# v1.5.0: new ON POINT Genesis routes

Changes since v1.4.0. This release adds four Genesis routes to ON POINT and corrects two existing ones. GOTO, DOGEAR
and Tools work as they did in v1.4.0. ON POINT runs on the X4 Pro only, so on the X4 this release changes nothing but
the version number.

## New ON POINT routes

- **AIRPORT TRANSFERS:** PITX ↔ Clark Airport.
- **NORTH LUZON:** Cubao ↔ Baguio, Pasay ↔ Baguio, and Clark Airport ↔ Balanga.

Your collections and main routes stay as you set them.

## Timetable changes

- **Clark Airport → NAIA T3** now includes PITX-bound trips that stop at Terminal 3.
- **NAIA T3 ↔ PITX is now PROVISIONAL:** its trip list may no longer be complete, and departures may vary.

## About these timetables

Times come from Genesis's published schedules, dated September to November 2026. The boards give an "as of" date.

- Bus classes are combined.
- Holiday and peak-season trips may differ. We found no holiday schedule from Genesis, and its boards say times can
  change without notice.
- Cubao → Baguio and Pasay → Baguio run fewer trips on Tuesdays and Wednesdays. Some Deluxe trips run only from
  Thursday to Monday.
- Baguio → Pasay combines Genesis's NAIA and Pasay lists.
- Genesis's Cubao → Clark board prints a "1:10 AM" trip between 11:10 AM and 3:10 PM. ON POINT shows it as 1:10 PM.
